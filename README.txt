Retro Racing - PHONE VERSION
============================
Portrait (upright), like the original iPhone game. If you turn the phone sideways the picture rotates
back, so the game always stays upright on the phone.

Open index.html in the phone's browser, with the "music" folder kept next to it.

Touch controls
- Bottom-left arrows: steer left / right
- Bottom-right button: accelerate (hold)
- II (top-left): pause
- ♪ (top-left): skip to the next song
- Pause menu / Options: "Song" button (tap left side = previous, right side = next)
- Volume: Options > Sound Volume / Music Volume (tap left / right half)
- Bluetooth controllers also work.
- 2 Player split-screen is PC-only.

Getting it onto a phone: copy this whole "Phone Version" folder to the phone (for example through
Google Drive, OneDrive or a USB cable) and open index.html in the browser.

The PC version is unchanged in ..\RetroRacing (Play Retro Racing.bat).
